# Tienda en línea - Frontend

Interfaz en HTML5, CSS3 y JavaScript que consume la API de productos.

## Uso

1. Levanta el backend: https://github.com/TU-USUARIO/tienda-backend
2. Abre esta carpeta en VS Code y usa **Go Live** (extensión Live Server).
3. La página se abre en http://127.0.0.1:5500/index.html

> El frontend espera la API en `http://localhost:3000/api/products`
> (se cambia en `js/api.js`).
